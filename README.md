# מעבר לדמיון — פרויקט סיום בבינה מלאכותית

תערוכת משחקים ואפליקציות של תלמידי כיתה ז׳ בתיכון דעת כוכב השחר.

## מבנה האתר
- `index.html` — גלריית הסיום
- `view.html` — צפייה בפרויקט יחיד
- `projects.js` — נתוני הפרויקטים
- `p/` — תשעת קובצי ה־HTML של התלמידים

## פרסום ב־Vercel
1. Add New → Project → Import Git Repository.
2. לבחור `shimonc29/kochav-hashachar-ai`.
3. לבחור Framework Preset: `Other`.
4. להשאיר Root Directory בתור `./`, ללא Build Command.
5. ללחוץ Deploy.

אין צורך בהתקנת חבילות או בבנייה: האתר הוא HTML/CSS/JavaScript סטטי. חלק מהמשחקים משתמשים ב־CDN ודורשים אינטרנט.
