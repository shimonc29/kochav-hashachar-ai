# מעבר לדמיון — תערוכת פרויקטי AI

פרויקט סיום של תלמידי כיתה ז׳, תיכון דעת כוכב השחר.

אתר סטטי המתאים לפרסום ישירות באמצעות Vercel (Framework Preset: Other, ללא Build Command).

- `index.html` — גלריית הפרויקטים
- `view.html` — עמוד פתיחת פרויקט
- `projects.js` — מידע על הפרויקטים
- `p/` — תשעת המשחקים והכלים המקוריים

בהנחיית שמעון כהן · AI Builder.
